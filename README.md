# 🚆 AI Railway Crack Detection System

## Overview

An AI-powered railway crack detection system using:

- YOLOv8
- OpenCV
- ESP32
- Python

The system detects cracks in real time, displays a professional inspection UI, logs detections, and controls hardware indicators through an ESP32.

---

## Features

- ✅ Real-time crack detection
- ✅ Bounding boxes
- ✅ Confidence scores
- ✅ Crack classification
- ✅ Detection logging
- ✅ Automatic image saving
- ✅ ESP32 LED integration
- ✅ Professional UI
